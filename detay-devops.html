Teknik Gerekçe

Kubernetes iş yükleri, container imajları ve çalışma zamanı (runtime) metadataları /var/lib altında kalıcı veriler oluşturur. Bu nedenle, işletim sistemi diskiyle depolama darboğazı (storage contention) yaşanmasını önlemek için bu dizine özel 275 GB'lık bir alan ayrılmıştır. Sistem logları, bakım kolaylığı ve hata izolasyonunu artırmak amacıyla /var/log altında izole edilmiştir. Düğüm kurtarma (node recovery) ve sorun giderme (troubleshooting) süreçlerini basitleştirmek için bilinçli olarak LVM kullanılmamıştır.

HAProxy Yapılandırması

k8s-lb-01 (192.168.50.10) üzerinde Kubernetes API trafiği TCP 6443 portundan 192.168.50.11–13 adresli master düğümlere roundrobin ile dağıtılır.

haproxy.cfg

frontend k8s-api
  bind *:6443
  mode tcp
  default_backend k8s-masters

backend k8s-masters
  mode tcp
  balance roundrobin
  server master1 192.168.50.11:6443 check
  server master2 192.168.50.12:6443 check
  server master3 192.168.50.13:6443 check
