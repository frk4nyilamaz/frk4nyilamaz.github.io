Görüntü İşleme ve Nesne Tespiti

Fiziksel bir iş istasyonunda (Precision 3630), ağ, donanım ve derleyici (compiler) yapılandırmaları sıfırdan kurularak Ubuntu 24.04 üzerinde YOLOv8 tabanlı gerçek zamanlı nesne tespiti projesi gerçekleştirilmiştir.

YOLOv8 PyTorch
CUDA 12.2 / cuDNN 9.6

Proje Özeti

Kamera görüntüsü üzerinde YOLOv8 modeli ile nesne tespiti yapıldı. PyTorch ve CUDA kullanıldı. Standart pip install opencv-python paketi CUDA ve GStreamer desteği içermediği için OpenCV 4.11 kaynak koddan derlendi.

Kullanılan Teknolojiler

  • Model: YOLOv8
  • Framework: PyTorch
  • Görüntü İşleme: OpenCV 4.11
  • GPU: CUDA 12.2, cuDNN 9.6
  • Kamera: GStreamer, V4L2

OpenCV Source Build

Standart pip paketi yerine, CUDA 12.2, cuDNN 9.6, GStreamer ve V4L2 desteklerinin aktif edilebilmesi için OpenCV 4.11 kaynak koddan derlenmiştir.

Sistem Mühendisliği Kararları

Ağ ve Derleyici (Compiler) Uyumu

Ubuntu 24.04 üzerinde NetworkManager çakışmalarını önlemek için yüksek öncelikli 99-netplan.yaml ile statik IP yapılandırıldı. İşletim sistemi NVMe diske kurulup, veri diski izole edildi. CUDA 12.2 ile gelen varsayılan GCC 13 uyumsuzluğunu aşmak için GCC 12 kurularak test araçları başarıyla derlendi.

PEP 668 Kısıtlaması

Ubuntu 24'ün getirdiği externally-managed-environment (PEP 668) kısıtlamalarına takılmamak adına, sisteme global pip müdahalesi yapılmadı. numpy paketi apt üzerinden kurularak CMake'in Python ortamını doğru tanıması sağlandı.

Yazılım ve Mimari Özellikler

  • ✓ Özel OpenCV Derlemesi: Standart paketlerin yetersizliği nedeniyle CUDA, cuDNN, FFmpeg, GStreamer ve V4L2 donanım bayraklarıyla saatler süren kaynak kod (source) derlemesi yapıldı.
  • ✓ Türkçe Karakter (FreeType): OpenCV'nin varsayılan metin çizicisi Türkçe desteklemediği için, Pillow ve FreeType kullanılarak özel bir render katmanı yazıldı.
  • ✓ Etiket Kayıt Sistemi: Modelin tespit ettiği nesnelerin İngilizce etiketlerini kalıcı ID ile source.json'a kaydeden ve tr.json'dan çevirisini çeken dinamik bir yapı kuruldu.

OpenCV Derleme

CMake ile aşağıdaki bayraklar aktif edilerek OpenCV 4.11 derlendi. Derleme sonrası cv2.getBuildInformation() ile CUDA, GStreamer ve V4L2 destekleri doğrulandı.

CMake (özet)

cmake -D WITH_CUDA=ON \
  -D WITH_CUDNN=ON \
  -D WITH_GSTREAMER=ON \
  -D WITH_V4L=ON ..

Derleme Doğrulama

>>> import cv2

>>> print(cv2.getBuildInformation())

GStreamer: YES

v4l/v4l2: YES

CUDA: YES (12.2)

cuDNN: YES (9.6)
